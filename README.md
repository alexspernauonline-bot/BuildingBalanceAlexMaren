* Feature 2

### Controls
Parkour Level:
WASD für Bewegung
[Space] Springen
[Shift] Sprinten
[] Ducken

Bau Level:
links-klick für aufheben und platzieren
rechts-klick um Farbe (Gewicht) des Blocks zu wechseln
R Rotieren eines Blocks
